Staggering is just keyframe offsets in a single timeline. There is no `Stagger` or `Parallel` wrapper in Elucim Documents.

## Staggered reveal

```ts
timelines: {
  intro: {
    id: 'intro',
    duration: 48,
    tracks: [
      { target: 'step-1', property: 'opacity', keyframes: [{ frame: 0, value: 0 }, { frame: 18, value: 1 }] },
      { target: 'step-2', property: 'opacity', keyframes: [{ frame: 8, value: 0 }, { frame: 26, value: 1 }] },
      { target: 'step-3', property: 'opacity', keyframes: [{ frame: 16, value: 0 }, { frame: 34, value: 1 }] },
      { target: 'step-4', property: 'opacity', keyframes: [{ frame: 24, value: 0 }, { frame: 42, value: 1 }] },
    ],
  },
}
```

## Parallel reveal

Elements run in parallel when their keyframes use the same frame range:

```ts
tracks: [
  { target: 'circle', property: 'opacity', keyframes: [{ frame: 0, value: 0 }, { frame: 30, value: 1 }] },
  { target: 'label', property: 'opacity', keyframes: [{ frame: 0, value: 0 }, { frame: 30, value: 1 }] },
]
```

Agent helpers can create this structure for common cases:

```ts
import { addRevealTimeline } from '@elucim/dsl/agent';

const updated = addRevealTimeline(doc, {
  id: 'intro',
  targets: ['step-1', 'step-2', 'step-3', 'step-4'],
  preset: 'staggeredFadeIn',
  stagger: 8,
}).document;
```
