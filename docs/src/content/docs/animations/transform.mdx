Use `layout` for static placement and timelines for motion. Normalized documents animate `translate`, `scale`, and `rotate` through timeline tracks instead of `<Transform>` or `<Morph>` wrappers.

## Move an element

```ts
timelines: {
  slideIn: {
    id: 'slideIn',
    duration: 45,
    tracks: [
      { target: 'dot', property: 'translate', keyframes: [{ frame: 0, value: [-120, 0] }, { frame: 45, value: [0, 0], easing: 'easeOutCubic' }] },
      { target: 'dot', property: 'opacity', keyframes: [{ frame: 0, value: 0 }, { frame: 20, value: 1 }] },
    ],
  },
}
```

## Rotate and scale

```ts
tracks: [
  { target: 'orbit', property: 'rotate', keyframes: [{ frame: 0, value: 0 }, { frame: 60, value: 360 }] },
  { target: 'orbit', property: 'scale', keyframes: [{ frame: 0, value: 0.8 }, { frame: 60, value: 1.2 }] },
]
```

## Change appearance

`fill` and `stroke` tracks can interpolate hex colors. Use semantic tokens for static theme-aware colors and hex values when a color transition must interpolate.

```ts
tracks: [
  { target: 'card', property: 'fill', keyframes: [{ frame: 0, value: '#6c5ce7' }, { frame: 45, value: '#4ecdc4' }] },
]
```
