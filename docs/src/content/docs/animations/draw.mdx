Normalized documents do not use `Draw` or `Write` wrappers. Use timeline tracks over visible properties such as `opacity`, `stroke`, `fill`, `scale`, or `translate`. Stroke-dash reveal support can be modeled as element props plus a timeline once a target primitive exposes a timeline-safe dash property.

## Reveal a stroke-based shape

```ts
elements: {
  orbit: {
    id: 'orbit',
    type: 'circle',
    props: { type: 'circle', cx: 250, cy: 125, r: 60, stroke: '$accent', strokeWidth: 3, fill: 'none', opacity: 0 },
  },
},
timelines: {
  intro: {
    id: 'intro',
    duration: 40,
    tracks: [
      { target: 'orbit', property: 'opacity', keyframes: [{ frame: 0, value: 0 }, { frame: 40, value: 1 }] },
    ],
  },
}
```

## Reveal text after the shape

```ts
elements: {
  label: {
    id: 'label',
    type: 'text',
    props: { type: 'text', x: 250, y: 132, content: 'Draw', fill: '$accent', fontSize: 16, textAnchor: 'middle', opacity: 0 },
  },
},
timelines: {
  intro: {
    id: 'intro',
    duration: 60,
    tracks: [
      { target: 'orbit', property: 'opacity', keyframes: [{ frame: 0, value: 0 }, { frame: 40, value: 1 }] },
      { target: 'label', property: 'opacity', keyframes: [{ frame: 30, value: 0 }, { frame: 60, value: 1 }] },
    ],
  },
}
```

For generated scenes, prefer these explicit tracks so editors and agents can inspect, patch, and reorder motion without understanding React wrapper trees.
