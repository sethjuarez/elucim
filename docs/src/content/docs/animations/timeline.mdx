description: Coordinate normalized scene motion with keyframes and state machines.

## Overview

In normalized Elucim documents, timelines are named clips. Each timeline contains tracks that target stable element IDs and animate a small safe property set: `opacity`, `translate`, `scale`, `rotate`, `fill`, and `stroke`.

State machines decide which timeline is active and how the scene moves from Entry through states and transitions.

## A single timeline

```ts
timelines: {
  intro: {
    id: 'intro',
    duration: 60,
    tracks: [
      { target: 'title', property: 'opacity', keyframes: [{ frame: 0, value: 0 }, { frame: 20, value: 1 }] },
      { target: 'line', property: 'opacity', keyframes: [{ frame: 25, value: 0 }, { frame: 60, value: 1 }] },
    ],
  },
}
```

## State-machine playback

```ts
defaultStateMachine: 'main',
stateMachines: {
  main: {
    id: 'main',
    entry: 'intro',
    states: {
      intro: { timeline: 'intro' },
      focus: { timeline: 'focus' },
    },
    transitions: [
      { id: 'entry-start', from: 'entry', to: 'intro', trigger: 'onStart' },
      { id: 'intro-next', from: 'intro', to: 'focus', exitTime: 1 },
    ],
  },
}
```

## Preview a frame

Use low-level helpers when a host needs to inspect a static frame:

```ts
import { applyTimelineFrame } from '@elucim/dsl';

const previewDoc = applyTimelineFrame(doc, 'intro', 30);
```

For most React rendering, pass the full document to `<DslRenderer dsl={doc} />` and let the default state machine run.
